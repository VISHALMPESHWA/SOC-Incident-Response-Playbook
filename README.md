# SOC-Incident-Response-Playbook

This repository contains practical SOC notes and checklists based on
real-world security operations experience.

The goal is to document structured approaches for:
- SIEM alert triage
- Phishing investigations
- Endpoint investigation using EDR tools
- Incident documentation and escalation

## Tools & Concepts Covered
- SIEM: Azure Sentinel, Splunk, QRadar, Sumo Logic
- EDR: Microsoft Defender for Endpoint, CrowdStrike Falcon
- Incident Types: Phishing, Malware, Credential Abuse
- Frameworks: MITRE ATT&CK (mapping during investigation)

This repository is intended for learning and reference purposes.
